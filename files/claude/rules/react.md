## 스타일 중복 처리

- 중복된 스타일 값(클래스 문자열, 스타일 객체 등)을 상수로 빼서 돌려쓰는 방식으로 해결하지 말 것.
- 중복은 아래 순서로 판단:
    1. 프로젝트에 이미 있는 공용 컴포넌트를 먼저 찾아서 사용
    2. 같은 파일 안의 반복은 데이터 + 반복 렌더링으로 처리
    3. 구조·동작까지 반복되면 컴포넌트로 분리
    4. 변형(크기, 상태, 색 등)은 그 컴포넌트 안에서 프로젝트의 기존 방식으로 표현
- 스타일링 방식은 새로 들이지 말고, 프로젝트에서 이미 쓰는 방식을 확인해서 따를 것.
- 우연히 3번 까지 겹치는 건 그대로 둬도 됨.
